根目录通过 pnpm-workspace.yaml 将 apps/web 与 apps/agent 纳入同一依赖图，顶层 package.json 的 scripts 统一转发到 @cos/web，形成跨语言子包的统一入口。Web 端基于 langchain-ai/agent-chat-ui 官方源码基线，通过 LYL_* 环境变量配置模型提供者；Agent 端使用 Python 3.12 + uv + LangGraph 提供最小可运行 messages Agent。两端通过 HTTP/WebSocket 流式协议通信，Thread 状态由 langgraph dev 的内存存储维持。docs/ 目录存放 PRD 与 SPEC，作为产品需求与技术规格的唯一权威来源，约束前端与 Agent 的实现边界。
