# 第十二部分：评测与测试

## 40. 能力 Eval

建立真实问题数据集，至少 30 条，覆盖：

- 产品方向；
- 技术选型；
- 工作优先级；
- 职业选择；
- 生活安排；
- 过度分析；
- 信息不足；
- 历史诊断。

每条包含：

- 用户背景；
- 历史上下文；
- 当前问题；
- 高质量参谋标准；
- 不可接受输出。

## 41. 对比基线

同一个模型比较：

A. 通用聊天 Prompt  
B. 刘亚楼 Agent，无长期记忆  
C. 刘亚楼 Agent，有长期记忆

评分：

- 问题重构准确性；
- 主要矛盾识别；
- 信息价值；
- 建议明确性；
- 个性化；
- 可执行性；
- 风险诚实度。

## 42. 记忆 Eval

- 是否检索正确历史；
- 是否遗漏关键约束；
- 是否引用错误或过时记忆；
- 是否将无关历史强行套入；
- 是否正确展示冲突；
- 诊断是否有证据和反例。

## 43. 调研 Eval

- 来源真实性；
- 关键事实准确率；
- 一手来源比例；
- 证据与结论绑定；
- 是否过度调研；
- 新信息是否改变判断；
- 不确定性表达。

## 44. 前端测试

- Thread 切换；
- 新建会商；
- Stream 中断与恢复；
- Interrupt 选择和恢复；
- Artifact 打开、关闭和版本；
- 文件上传；
- 移动端 Drawer；
- 错误恢复；
- 隐藏内部消息；
- 长消息渲染。

# 第十三部分：非功能要求

## 45. 性能

- 普通会商首个 Token：P95 < 3 秒；
- 本地记忆检索：P95 < 500ms；
- Thread 打开：P95 < 1.5 秒；
- Artifact 更新：事件到 UI < 500ms；
- 深度调研无硬性总时限，但必须在 5 秒内显示阶段状态。

## 46. 稳定性

- Stream 中断后可恢复；
- 工具单点失败不应导致全部调研失败；
- Artifact 最终状态必须可重复读取；
- 同一个 Interrupt 不得重复提交；
- Thread 与 user_id 绑定校验；
- 数据写入幂等。

## 47. 兼容性

第一版支持：

- Chrome / Edge 最新两个版本；
- 桌面端优先；
- 移动 Web 基本可用；
- 暂不开发原生客户端。

# 第十六部分：DoD

## 53. 开发完成定义

一个功能只有同时满足以下条件才算完成：

- 业务流程可用；
- Schema 已定义；
- 前后端类型一致；
- 错误和空状态已处理；
- 有单元或集成测试；
- 有至少一个真实会商用例；
- 结果进入 Eval；
- 不泄漏密钥或私有数据；
- 文档更新；
- 可在本地一键启动。

# 附录 A：MVP 最小 Graph

```python
builder = StateGraph(CounselState)

builder.add_node("intake", intake)
builder.add_node("retrieve_context", retrieve_context)
builder.add_node("reframe", reframe_problem)
builder.add_node("research", research_if_needed)
builder.add_node("reason", counsel_reasoning)
builder.add_node("synthesize", synthesize_counsel)
builder.add_node("persist", persist_proposals)

builder.add_edge(START, "intake")
builder.add_edge("intake", "retrieve_context")
builder.add_edge("retrieve_context", "reframe")
builder.add_conditional_edges(
    "reframe",
    route_after_reframe,
    {
        "interrupt": "reframe",
        "research": "research",
        "reason": "reason",
    },
)
builder.add_edge("research", "reason")
builder.add_edge("reason", "synthesize")
builder.add_edge("synthesize", "persist")
builder.add_edge("persist", END)
```

该示例表达最低复杂度，不要求每个逻辑都拆成独立节点。
