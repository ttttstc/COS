## 1. 产品定位与设计哲学

### 1.1 核心设计原则

| 原则 | 说明 |
|------|------|
| **数据优先 (Data-First)** | 界面不竞争数据。所有视觉元素服务于信息本身，克制装饰 |
| **专业克制** | 法律科技不需要花哨。安静、可信、精确 |
| **透明可见** | 合同全生命周期每一阶段可见可追溯，状态一目了然 |
| **跨法域平权** | 不偏向任何法域的工作流，各区域法律审核作为一等产品概念 |

### 1.2 视觉 DNA

- 深色基底奠定专业权威感
- 玻璃材质传达通透与透明度（呼应「合规可见」的品牌承诺）
- 霓虹绿强调色 = 激活态 / 完成态 / 安全态
- 3D 堆叠卡片 = 合同层级与嵌套关系

### 1.3 合同全生命周期视图模型

```
草拟 → 审核 → 谈判 → 批准 → 签署 → 监控 → 续约
  │      │      │      │      │      │      │
  ▼      ▼      ▼      ▼      ▼      ▼      ▼
独立视图 独立视图 独立视图 独立视图 独立视图 独立视图 独立视图
         └─────────── 自动化合规路径 ───────────┘
```

## 3. Liquid Glass 材质体系

### 3.1 四级材质定义

参考 visionOS Glass 系统，在暗色模式下定义四级半透明材质：

| 级别 | Token | 背景 | 模糊 | 饱和度 | 边框 | 用途 |
|------|-------|------|------|--------|------|------|
| **thin** | `--glass-thin` | `rgba(255,255,255,0.06)` | `blur(12px)` | `saturate(120%)` | `1px solid rgba(255,255,255,0.06)` | 卡片、标签、次要容器 |
| **regular** | `--glass-regular` | `rgba(255,255,255,0.08)` | `blur(20px)` | `saturate(140%)` | `1px solid rgba(255,255,255,0.10)` | 面板、弹出菜单、侧边栏 |
| **clear** | `--glass-clear` | `rgba(255,255,255,0.04)` | `blur(16px)` | `saturate(110%)` | `1px solid rgba(255,255,255,0.04)` | 悬浮按钮、工具栏图标组 |
| **thick** | `--glass-thick` | `rgba(255,255,255,0.14)` | `blur(24px)` | `saturate(160%)` | `1px solid rgba(255,255,255,0.18)` | 选中态、悬停激活态、模态弹窗 |

### 3.2 亮色模式对应的材质值

| 级别 | 背景 | 模糊 | 边框 |
|------|------|------|------|
| **thin** | `rgba(255,255,255,0.45)` | `blur(10px) saturate(130%)` | `1px solid rgba(0,0,0,0.04)` |
| **regular** | `rgba(255,255,255,0.55)` | `blur(16px) saturate(140%)` | `1px solid rgba(0,0,0,0.06)` |
| **clear** | `rgba(255,255,255,0.25)` | `blur(12px) saturate(120%)` | `1px solid rgba(0,0,0,0.03)` |
| **thick** | `rgba(255,255,255,0.72)` | `blur(20px) saturate(150%)` | `1px solid rgba(0,0,0,0.08)` |

### 3.3 使用规则

- ✅ 玻璃元素仅用于导航层和控件层，形成与内容层的明确分离
- ✅ 内容层（列表、表格、文档）使用不透明实体背景
- ✅ 玻璃叠玻璃仅在“选中态浮起”场景允许（如：sidebar 选中项用 thick 浮于 regular）
- ❌ 不在内容层使用玻璃材质
- ❌ 不混合使用四级玻璃制造混乱层次

## 4. 字体排印

### 4.1 字体家族

| 优先级 | 字体 | 用途 |
|--------|------|------|
| 第一 | **Urbanist** | 品牌字体（ClauseOS 官方选用），现代几何无衬线，用于标题和导航 |
| 第二 | **Inter** | 正文 UI 字体，屏幕可读性最优，用于长文本和数据 |
| 第三 | **SF Pro Display / SF Pro Text** | macOS/iOS 原生回退 |
| 回退 | -apple-system, sans-serif | 系统默认无衬线 |

### 4.2 字号层级

| 样式名称 | 字号 | 行高 | 字重 | 用途 |
|----------|------|------|------|------|
| `display-xl` | 36px | 1.2 | Bold (700) | 仪表盘关键数据大字 |
| `display-lg` | 28px | 1.2 | Bold (700) | 统计卡片数字 |
| `title-lg` | 24px | 1.3 | Semibold (600) | 页面标题 |
| `title-md` | 20px | 1.3 | Semibold (600) | 区块标题 |
| `title-sm` | 16px | 1.4 | Medium (500) | 卡片标题 |
| `body` | 14px | 1.5 | Regular (400) | 正文/说明 |
| `body-sm` | 13px | 1.5 | Regular (400) | 辅助信息 |
| `caption` | 12px | 1.4 | Medium (500) | 标签/徽章/状态 |
| `caption-sm` | 11px | 1.4 | Regular (400) | 最小文字/时间戳 |

### 4.3 字距与对齐规则

- 标题左对齐，数字居中对齐或右对齐（表格内）
- 数字与单位之间无空格：`128合同` `¥45,000`
- 日期统一格式：`2026-07-28 14:30`
- 英文/数字与中文之间自动留 1/4em（用 CSS `word-spacing` 或 `margin` 微调）

## 5. 间距与布局规范

### 5.1 间距 Token（8px 倍数体系）

| Token | 值 | 用途 |
|-------|-----|------|
| `--space-xs` | 4px | 紧密关联元素（图标+文字） |
| `--space-sm` | 8px | 按钮组内、标签间距 |
| `--space-md` | 16px | 组件内边距 |
| `--space-lg` | 24px | 卡片内边距、组件间距 |
| `--space-xl` | 32px | 区块间距 |
| `--space-2xl` | 48px | 主内容区大分隔 |
| `--space-3xl` | 64px | 页面级段落间距 |

### 5.2 页面布局模板

#### 三栏布局（主工作区）- 默认推荐

```
┌──────────┬──┬─────────────────────────┬──┬──────────┐
│          │  │                         │  │          │
│  导航栏   │  │     主内容区             │  │  详情面板 │
│  280px   │5 │     flex: 1              │5 │  400px   │
│          │p │                         │p │          │
│          │x │                         │x │          │
└──────────┴──┴─────────────────────────┴──┴──────────┘
```

- 导航栏：280px 固定宽度
- 分隔线：5px 可拖拽手柄
- 主内容区：flex: 1 自适应
- 详情面板：400px 固定宽度（可折叠）

#### 导航栏结构

- 顶部：产品 Logo + 名称（Urbanist Bold 18px）
- 中部：主导航菜单（图标24px + 文字14px，间距12px）
- 底部：用户头像（36px 圆）+ 设置/退出

#### 主内容区结构（仪表盘）

- 统计卡片行：4列网格，每列 flex: 1，间距 24px
- 可视化区：flex: 1 自适应，3D 卡片堆叠效果
- 时间轴：底部固定 200px，水平滚动

### 5.3 响应式断点

| 断点 | 宽度 | 布局变化 |
|------|------|---------|
| Desktop | ≥ 1440px | 三栏全展开 |
| Laptop | 1024-1439px | 导航栏缩至 64px 图标模式 |
| Tablet | 768-1023px | 详情面板折叠为底部抽屉 |
| Mobile | < 768px | 单栏，导航改底部 Tab Bar |

## 6. 圆角与阴影

### 6.1 圆角 Token

| Token | 值 | 用途 |
|-------|-----|------|
| `--radius-none` | 0 | 表格/分隔线 |
| `--radius-xs` | 4px | 小标签/徽章/时间轴点 |
| `--radius-sm` | 6px | 输入框/下拉菜单项 |
| `--radius-md` | 10px | 按钮/小卡片/菜单面板 |
| `--radius-lg` | 16px | 主卡片/模态弹窗 |
| `--radius-xl` | 20px | 大面板/图表容器 |
| `--radius-full` | 9999px | 胶囊按钮/头像/状态指示器 |

### 6.2 阴影系统（暗色模式）

| 层级 | CSS | 用途 |
|------|-----|------|
| `--shadow-sm` | `0 1px 3px rgba(0,0,0,0.3), inset 0 1px 0 rgba(255,255,255,0.03)` | 卡片/轻浮层 |
| `--shadow-md` | `0 4px 16px rgba(0,0,0,0.35), inset 0 1px 0 rgba(255,255,255,0.05)` | 弹出菜单/下拉 |
| `--shadow-lg` | `0 8px 32px rgba(0,0,0,0.45), inset 0 1px 0 rgba(255,255,255,0.06)` | 模态弹窗/通知 |
| `--shadow-glow` | `0 0 20px rgba(0,255,157,0.15), 0 4px 16px rgba(0,0,0,0.3)` | 主按钮/选中卡片激活态辉光 |
| `--shadow-3d` | `0 2px 6px rgba(0,0,0,0.4), 0 8px 24px rgba(0,0,0,0.3)` | 3D 堆叠卡片 |

### 6.3 3D 卡片堆叠效果

用于合同可视化视图：顶部卡片偏移 0，第二层偏移 Y+4px + 缩放 0.97，第三层 Y+8px + 缩放 0.94，每层透明度递减。悬停时最上层微浮 Y-4px。

## 8. 动效与过渡

### 8.1 动画 Token

| Token | 值 | 用途 |
|-------|-----|------|
| `--dur-fast` | 150ms | 微交互（hover 变色/图标缩放） |
| `--dur-normal` | 250ms | 标准过渡（卡片展开/菜单弹出） |
| `--dur-slow` | 400ms | 模态弹窗/页面切换 |
| `--ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | 入场/展开 |
| `--ease-in` | `cubic-bezier(0.4, 0, 1, 1)` | 退场/折叠 |
| `--ease-spring` | `cubic-bezier(0.25, 0.1, 0.25, 1)` | 弹性反馈/拖拽 |

### 8.2 关键动效

| 场景 | 效果 |
|------|------|
| 玻璃卡片悬停 | 背景透明度 +0.04、边框透明度 +0.06、轻微 Y 上浮 -2px |
| 按钮点击 | 缩放 0.97 → 回弹 1.0（150ms spring） |
| 菜单弹出 | 从触发点 scale(0.9) + opacity(0) → 展开（200ms ease-out） |
| 3D 堆叠卡片拖拽 | 顶部卡片 Y 浮动，层级卡片跟随偏移 |
| 状态切换 | 图标/颜色 crossfade（200ms） |
| 列表项删除 | 向右滑出 + opacity → 0（250ms）+ 下方元素上滑补位 |
| 页面切换 | 左右滑动（合同全生命周期阶段切换） |

### 8.3 性能约束

- 同时动画元素 ≤ 5 个
- 模糊滤镜（backdrop-filter）区域谨慎使用，大区域建议降级为纯色半透明
- 始终支持 `prefers-reduced-motion`：降级为 instant opacity 切换
