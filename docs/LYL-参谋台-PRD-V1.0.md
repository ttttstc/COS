## 核心定位

刘亚楼参谋台是一款由用户主动触发的个人战略参谋 Agent，聚焦三个高价值问题：

- 不知道下一步做什么；
- 面对多个选项难以决断；
- 主动诊断历史聊天与决策中的思维模式。

第一版重点验证参谋能力，不重点打磨 UI，不建设固定多 Agent 军团、Workflow 编辑器或现实任务执行平台。
